GIS 批量格式转换工具

ArcGIS Python Toolbox，支持 SHP / DWG / MDB / GDB / KML 五种格式批量互转，兼容 ArcMap 10.8 和 ArcGIS Pro。

PythonArcGISarcpyGIS

项目介绍

在日常 GIS 工作中，经常需要在不同格式之间转换数据。手动操作效率低且容易出错，因此开发了这个批量转换工具，只需在 ArcGIS 中导入工具箱即可一键完成格式转换。

功能特点

  • 五种格式互转：SHP、DWG、MDB、GDB、KML 任意方向批量转换
  • 批量处理：一次选择整个文件夹，自动扫描并转换所有匹配文件
  • 智能回退：DWG 转换自动检测许可，无 Data Interoperability 扩展时自动切换 ezdxf 模式
  • 坐标系统：支持输出时指定坐标系，自动投影变换
  • 双平台兼容：同时支持 ArcMap 10.8 和 ArcGIS Pro
  • 零依赖：纯 Python 编写，仅依赖 arcpy（ArcGIS 内置）和可选的 ezdxf

使用方法

  • 在 ArcGIS 中打开目录窗口
  • 右键文件夹 → 添加工具箱 → 选择 GIS_Converter.pyt
  • 展开工具箱，双击需要的转换工具
  • 选择输入文件和输出位置，点击确定
