Web 地图标注系统 NEW

基于 Vue3 + FastAPI 的全栈地图标注工具，支持多底图切换、绘制标注、属性编辑、空间查询、GeoJSON 导入导出。

Vue3 TypeScript Leaflet FastAPI SQLAlchemy 全栈
📦 GitHub 源码

项目介绍

这是一个 Web 端地图标注系统，前后端分离架构。前端使用 Vue3 + Leaflet 实现地图渲染和绘制交互，后端使用 FastAPI + SQLAlchemy 提供 RESTful API 和数据持久化。支持多种底图切换、点/线/面绘制、图层管理、搜索查询、坐标转换等功能。

项目特点：

  • 前后端分离，RESTful API 设计
  • 响应式 UI，支持深色模式
  • 数据持久化，刷新不丢失
  • GeoJSON 标准格式导入导出，兼容 QGIS/ArcGIS
  • 零配置启动（SQLite 数据库）

功能特性

🗺️ 多底图切换

支持高德地图、OpenStreetMap、天地图三种底图，一键切换。

✏️ 绘制工具

点、线、多边形、矩形绘制，支持编辑顶点、拖拽移动、删除。

📝 属性编辑

编辑标注名称、描述、颜色、线宽、透明度等样式属性。

📂 图层管理

新建/删除图层，切换可见性，标注自动关联到当前图层。

🔍 搜索查询

按名称/描述实时搜索标注，点击结果自动定位到地图。

📐 测量工具

点击画线测量距离，3 点以上自动计算面积，支持多种单位。

📤📥 导入导出

支持 GeoJSON 格式导入导出，兼容主流 GIS 软件。

🔄 坐标转换

内置 WGS-84 / GCJ-02 / BD-09 坐标系转换工具。

使用教程

快速开始

  1. 启动后端服务 进入项目目录，激活虚拟环境，运行 python -m uvicorn backend.app.main:app --port 8000
  2. 启动前端服务 新开终端，运行 npm run dev，浏览器打开 http://localhost:5173
  3. 开始绘制 点击左侧工具栏选择绘制类型（点/线/面/矩形），在地图上点击绘制
  4. 编辑属性 绘制完成后右侧面板自动弹出，输入名称、描述，调整样式后保存

绘制标注

  • 点标注：点击「绘制标记」按钮 → 在地图上点击放置
  • 线段：点击「绘制线段」按钮 → 依次点击添加节点 → 双击完成
  • 多边形：点击「绘制多边形」按钮 → 依次点击顶点 → 点击第一个点闭合
  • 矩形：点击「绘制矩形」按钮 → 点击并拖拽画出范围

编辑与删除

  • 移动：点击「拖拽图层」按钮 → 拖拽标注到新位置
  • 改形状：点击「编辑图层」按钮 → 点击标注 → 拖拽蓝色顶点
  • 删除：点击「删除图层」按钮 → 点击标注，或在属性面板中点「删除」

图层管理

  • 左下角图层面板，点击「＋」新建图层
  • 点击图层名称切换当前图层（新绘制的标注归属当前图层）
  • 点击「👁」图标切换图层可见性
  • 点击「🗑」图标删除图层（标注会迁移到默认图层）

搜索与测量

  • 搜索：左上角搜索框输入关键词，实时搜索，点击结果定位
  • 测量：点击底部「📐 测量」按钮 → 在地图上点击画线 → 实时显示距离和面积

导入导出

  • 导入：点击顶部「📤 导入」按钮 → 选择 .geojson 文件 → 自动导入
  • 导出：点击顶部「📥 导出」按钮 → 自动下载 GeoJSON 文件
  • 导出的 GeoJSON 可直接在 QGIS、ArcGIS 等 GIS 软件中打开

技术架构

前端框架Vue 3 + TypeScript + Vite
地图引擎Leaflet + Leaflet-Geoman（绘制插件）
后端框架FastAPI（Python 异步高性能）
ORMSQLAlchemy 2.0
数据库SQLite（可切换 PostgreSQL + PostGIS）
数据格式GeoJSON（标准地理数据格式）
部署方式Uvicorn ASGI 服务器

API 接口

方法路径说明
POST/api/annotations创建标注
GET/api/annotations查询列表
GET/api/annotations/search?q=搜索标注
GET/api/annotations/spatial/nearby附近标注查询
GET/api/annotations/export导出 GeoJSON
GET/api/annotations/{id}查询单个
PUT/api/annotations/{id}更新标注
DEL/api/annotations/{id}删除标注
POST/api/layers创建图层
GET/api/layers查询所有图层
PUT/api/layers/{id}更新图层
DEL/api/layers/{id}删除图层
