## 1. 启动系统

### 方式一：双击启动（推荐）

找到项目文件夹，双击 `start-dev.bat`，会自动打开两个窗口：
- 一个运行后端服务
- 一个运行前端服务

等待看到以下提示即启动成功：
```
前端: http://localhost:5173
后端: http://localhost:8000
```

### 方式二：手动启动

打开两个终端窗口：

**终端 1 — 启动后端：**
```bash
cd C:\Users\11098\Desktop\map-annotation-system
.venv\Scripts\activate
python -m uvicorn backend.app.main:app --port 8000
```

**终端 2 — 启动前端：**
```bash
cd C:\Users\11098\Desktop\map-annotation-system
npm run dev
```

### 打开浏览器

在浏览器地址栏输入：**http://localhost:5173**

## 3. 底图切换

在地图**右上角**有三个按钮：

| 按钮 | 说明 |
|------|------|
| **高德地图** | 中文地图，适合国内使用（默认） |
| **OpenStreetMap** | 开源全球地图，英文标注 |
| **天地图** | 国家标准地图（需要申请 key） |

**操作：** 点击按钮即可切换，当前选中的按钮会高亮显示。

## 4. 绘制标注

### 绘制点（标记）

1. 点击左侧工具栏的 **📍 绘制标记** 按钮（按钮会高亮）
2. 在地图上**点击**你想放置标记的位置
3. 右侧会自动弹出属性编辑面板
4. 输入名称和描述，点击**保存**

### 绘制线段

1. 点击 **📏 绘制线段** 按钮
2. 在地图上**依次点击**，每点击一次添加一个节点
3. **双击**最后一个点完成绘制
4. 编辑属性并保存

### 绘制多边形

1. 点击 **⬡ 绘制多边形** 按钮
2. 在地图上**依次点击**顶点
3. **点击第一个顶点**闭合多边形
4. 编辑属性并保存

### 绘制矩形

1. 点击 **▭ 绘制矩形** 按钮
2. 在地图上**点击并拖拽**，画出矩形范围
3. 松开鼠标完成绘制
4. 编辑属性并保存

### 小技巧

- 绘制过程中按 **Esc** 可以取消当前绘制
- 每个标注绘制完成后会自动打开属性面板
- 标注默认归属到当前选中的图层

---

## 5. 编辑标注

### 移动标注

1. 点击左侧工具栏的 **🖐️ 拖拽图层** 按钮
2. 在地图上**点击并拖拽**标注到新位置
3. 位置变更会自动保存到数据库

### 修改形状

1. 点击 **✏️ 编辑图层** 按钮
2. 在地图上**点击**你想编辑的标注
3. 标注的顶点会出现**蓝色小方块**
4. **拖拽方块**可以修改形状
5. 修改完成后点击地图空白处确认

---

## 6. 删除标注

### 方式一：工具栏删除

1. 点击 **🗑️ 删除图层** 按钮
2. 在地图上**点击**你想删除的标注
3. 标注会被立即删除

### 方式二：属性面板删除

1. **点击**地图上的标注，打开属性面板
2. 点击面板底部的 **删除** 按钮
3. 在弹出的确认框中点击**确定**

## 8. 图层管理

图层面板在地图**左下角**：

```
┌──────────────────┐
│ 图层管理       ＋ │
├──────────────────┤
│ 👁 ■ 默认图层   3 │  ← 当前图层（蓝色高亮）
│ 👁 ■ 标注图层   5 │
│ 👁 ■ 参考线     2 │
└──────────────────┘
```

### 新建图层

1. 点击右上角的 **＋** 按钮
2. 输入图层名称
3. 按 **Enter** 或点击**确定**

### 切换当前图层

- **点击**图层名称，切换为当前图层
- 新绘制的标注会自动归属到当前图层

### 切换可见性

- 点击图层前面的 **👁** 图标
- 隐藏的图层上的标注不会显示在地图上

### 删除图层

- 点击图层右侧的 **🗑** 图标
- 该图层上的所有标注会被删除
- 默认图层不能删除

## 10. 测量工具

在地图**底部信息栏**右侧：

### 开始测量

1. 点击 **📐 测量** 按钮（按钮变蓝，进入测量模式）
2. 在地图上**依次点击**，画出测量路径
3. 实时显示**总距离**
4. 点击 **3 个点以上**会自动计算**面积**

### 显示示例

```
距离: 1.23 公里 | 面积: 45.6 公顷 (4 个点，双击结束)
```

### 单位自动换算

| 距离 | 面积 |
|------|------|
| < 1000 米 → 显示米 | < 10000 平方米 → 显示平方米 |
| ≥ 1000 米 → 显示公里 | < 1000000 → 显示公顷 |
| | ≥ 1000000 → 显示平方公里 |

### 退出测量

- 点击 **退出测量** 按钮
- 或点击 **🗑 清除** 清除测量线

## 11. 导入 GeoJSON

如果你有现成的 GeoJSON 文件，可以直接导入：

1. 点击顶部工具栏的 **📤 导入** 按钮
2. 在文件选择器中选择 `.geojson` 或 `.json` 文件
3. 等待导入完成
4. 弹窗显示导入结果（成功/失败数量）

### 支持的格式

- **FeatureCollection**（标准 GeoJSON 集合）
- **单个 Feature**
- **直接的 Geometry 对象**（Point、LineString、Polygon）

### 支持的几何类型

| GeoJSON 类型 | 导入为 |
|-------------|--------|
| Point | 📍 点标注 |
| LineString | 📏 线段 |
| Polygon | ⬡ 多边形 |

### 属性映射

导入时会自动读取 Feature 的 properties：

| 属性字段 | 映射到 |
|---------|--------|
| `name` / `Name` / `NAME` | 标注名称 |
| `description` / `desc` | 标注描述 |
| `color` | 线颜色 |
| `fillColor` | 填充颜色 |

---

## 12. 导出 GeoJSON

1. 点击顶部工具栏的 **📥 导出** 按钮
2. 浏览器会自动下载 `.geojson` 文件
3. 文件名格式：`annotations-2026-06-24.geojson`

### 导出内容

导出的 GeoJSON 包含所有标注的：
- 几何数据（坐标）
- 属性（名称、描述、类型、样式）

可以直接在 QGIS、ArcGIS 等 GIS 软件中打开。

## 14. 常见问题

### Q: 地图显示不出来？

**A:** 检查网络连接。底图瓦片需要从互联网加载，确保能访问以下域名：
- `*.is.autonavi.com`（高德地图）
- `*.tile.openstreetmap.org`（OSM）

### Q: 标注保存后刷新页面就没了？

**A:** 确保后端服务正在运行。前端绘制的标注会通过 API 保存到后端数据库。如果后端没启动，数据只存在浏览器内存中。

### Q: 天地图显示不出来？

**A:** 天地图需要申请 API Key。去 [天地图开放平台](http://console.tianditu.gov.cn/) 注册并申请 key，然后在 `src/components/MapView.vue` 第 39 行替换 `tk=你的天地图key`。

### Q: 如何切换到 PostgreSQL 数据库？

**A:** 
1. 安装 PostgreSQL 并创建数据库
2. 在 `.env` 文件中修改：
   ```
   DATABASE_URL=postgresql://user:password@localhost:5432/map_annotations
   ```
3. 安装驱动：`pip install psycopg2-binary`
4. 重启后端服务

### Q: 如何部署到服务器？

**A:** 参考 README.md 中的「部署到服务器」章节。最简单的方式：
1. 上传代码到服务器
2. 安装 Node.js 和 Python
3. 运行 `start-prod.sh`
4. 用 Nginx 做反向代理

### Q: 坐标系是哪个？

**A:** 系统内部使用 **WGS-84** 坐标系（国际标准 GPS 坐标）。高德地图使用 GCJ-02 坐标系，会有一定偏移。如果需要精确对齐高德底图，可以使用 `src/utils/coordTransform.ts` 中的坐标转换函数。
